# 시연 전 손동작 연습

Vision Pro를 쓰기 전에 맥북 웹캠으로 BPA 360의 조작 7가지(눈으로 고르기와 손동작)를 연습하는 페이지입니다. 기기를 못 쓰는 사람(안경, 메이크업, 대기 시간)도 앱 흐름을 간접으로 체험할 수 있습니다.

- 주소: https://hoyeonpark1221.github.io/BPA360_web_page/practice/
- 처음 열 때 카메라를 허용하면, 손 인식 모델을 불러오는 데 5초쯤 걸립니다. 눈 인식(얼굴) 모델은 1단계를 하는 동안 뒤에서 받습니다.
- MediaPipe 파일을 CDN에서 받으므로 인터넷이 필요합니다.

## 단계

왼쪽 창에는 그 손동작으로 앱에서 무엇을 하는지(BPA 360에서는)와 기기에서 다른 점(Vision Pro에서는)이 나옵니다.

| 단계 | 웹캠에서 하는 동작 | 앱에서 쓰는 곳 |
|---|---|---|
| 1 맞대기 | 엄지·검지를 3번 맞댔다 떼기 | 모든 조작의 기본 핀치 |
| 2 보고 고르기 | 점 9개를 하나씩 보고 맞대 눈 설정을 한 뒤, 혈흔 1 → 3 → 2를 바라봐서 밝아지면 맞대 고르기 | 보고 핀치, 기기의 눈 설정 |
| 3 누르기 | 도구 막대의 그룹화 → 스티커 → 방향 펜 누르기 | 버튼 (보고 핀치) |
| 4 그룹 만들기 | 같은 방향 혈흔 3개를 사각형으로 감싸고, 혈흔을 가린 분류 창을 아래 막대로 옮긴 뒤, 대분류를 골라 그룹 생성 | 클러스터링 그룹화 (오른손 광선 + 핀치), 창 옮기기 |
| 5 스티커 | 방향 화살표를 끌어 붙이고, 골라서, 회전을 누르고, 링 손잡이를 돌려 ✓로 확정 | 방향 스티커 붙이기·회전 |
| 6 타원 맞추기 | 확대창의 타원을 Leading edge(돌리기)·끝(길이)·옆(폭)·안쪽(옮기기)으로 혈흔 몸통에 맞추고 측정 완료 | 방향성 판단의 축 측정 (충돌각) |
| 7 줄 잇기 | 흰 점을 집어 점선 원까지 줄 3개 잇기 | 방향성 판단의 줄 연결법 |

2단계의 시선은 MediaPipe Face Landmarker의 홍채·눈꺼풀 위치, 눈 방향 표정 값, 고개 돌림을 눈 설정 점 위치에 회귀로 맞춰 구합니다. 웹캠 시선은 화면에서 100~200px쯤 빗나가서, 가장 가까운 혈흔에 하이라이트를 붙입니다. 기기처럼 시선 커서는 보이지 않습니다. 맞게 고를 때마다 그 순간의 눈 모양으로 시선을 조금 더 맞춥니다. 2단계만 시선을 쓰고, 다른 단계는 손이 가리키는 곳을 씁니다.

완료 화면에는 연습하지 않는 기기 조작(키보드 받아쓰기, Digital Crown 길게 눌러 다시 가운데로)을 안내합니다.

## 운영자용 키

- `←` `→` 단계 이동, `R` 이 단계 다시, `Esc` 처음 화면
- `G` 2단계에서 시선 위치(노란 십자) 보이기·숨기기. 눈 설정이 어긋났는지 볼 때 씁니다.
- 웹캠이 안 되면 첫 화면의 **마우스로 해보기** (클릭 = 맞대기)
- 완료 화면은 25초 뒤, 연습 중 45초 동안 손이 안 보이면 처음 화면으로 돌아갑니다.

## 감도 조정

`index.html` 위쪽 상수를 고칩니다.

- `PINCH_ON` / `PINCH_OFF`: 맞댐으로 보는 엄지·검지 거리 (손바닥 크기 대비). 너무 예민하면 `PINCH_ON`을 낮춥니다.
- `REACH`: 카메라 화면 중 벽 전체로 늘릴 범위. 팔을 많이 움직여야 하면 범위를 좁힙니다.
- `LOOK_REACH` / `LOOK_SWITCH` / `LOOK_DWELL_MS`: 시선이 혈흔에 붙는 거리(장면 너비 비율), 다른 혈흔으로 바뀔 때 더 가까워야 하는 비율, 바뀌기 전에 머무는 시간. 하이라이트가 깜빡이면 `LOOK_DWELL_MS`를 늘립니다.
- `GAZE_RIDGE`: 시선 회귀의 규제 세기. 시선이 너무 흔들리면 키우고, 끝까지 안 따라오면 줄입니다.
- `CALIB`: 눈 설정 점 위치. 점을 줄이면 설정이 빨라지지만 덜 정확해집니다.
- `ALIGN_TOLERANCE`: 스티커 방향을 맞았다고 보는 각도 차이.
- `AXIS_FIT`: 타원을 맞았다고 보는 범위 (가운데 거리, 축 각도, 장축·단축 길이 비율). `AXIS_GAIN`은 손잡이가 손을 따라오는 비율.
