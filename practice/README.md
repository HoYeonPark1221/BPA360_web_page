# 시연 전 손동작 연습

Vision Pro를 쓰기 전에 맥북 웹캠으로 BPA 360의 손동작 4가지를 연습하는 페이지입니다. 기기를 못 쓰는 사람(안경, 메이크업, 대기 시간)도 앱 흐름을 간접으로 체험할 수 있습니다.

- 주소: https://hoyeonpark1221.github.io/BPA360_web_page/practice/
- 처음 열 때 카메라를 허용하면, 손 인식 모델을 불러오는 데 5초쯤 걸립니다.
- MediaPipe 파일을 CDN에서 받으므로 인터넷이 필요합니다.

## 단계

| 단계 | 웹캠에서 하는 동작 | 앱의 실제 입력 |
|---|---|---|
| 1 맞대기 | 엄지·검지를 3번 맞댔다 떼기 | 핀치 |
| 2 보고 집기 | 혈흔 3개를 가리켜 밝아지면 맞대서 고르기 | 보고 핀치 |
| 3 집고 끌기 | 흰 점을 집어 점선 원까지 줄 3개 잇기 | 보고 핀치한 채 끌기 |
| 4 가리켜 그리기 | 줄이 모이는 곳을 사각형으로 감싸기 | 오른손 광선 + 핀치 |

## 운영자용 키

- `←` `→` 단계 이동, `R` 이 단계 다시, `Esc` 처음 화면
- 웹캠이 안 되면 첫 화면의 **마우스로 해보기** (클릭 = 맞대기)
- 완료 화면은 25초 뒤, 연습 중 45초 동안 손이 안 보이면 처음 화면으로 돌아갑니다.

## 감도 조정

`index.html` 위쪽 상수를 고칩니다.

- `PINCH_ON` / `PINCH_OFF`: 맞댐으로 보는 엄지·검지 거리 (손바닥 크기 대비). 너무 예민하면 `PINCH_ON`을 낮춥니다.
- `REACH`: 카메라 화면 중 벽 전체로 늘릴 범위. 팔을 많이 움직여야 하면 범위를 좁힙니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
```

http://localhost:8000/practice/ 를 엽니다. 카메라는 `localhost`나 `https` 주소에서만 켜집니다.
