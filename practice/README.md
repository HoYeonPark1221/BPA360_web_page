# 시연 전 손동작 연습

Vision Pro를 쓰기 전에 맥북 웹캠으로 BPA 360의 손동작 5가지를 연습하는 페이지입니다. 기기를 못 쓰는 사람(안경, 메이크업, 대기 시간)도 앱 흐름을 간접으로 체험할 수 있습니다.

- 주소: https://hoyeonpark1221.github.io/BPA360_web_page/practice/
- 처음 열 때 카메라를 허용하면, 손 인식 모델을 불러오는 데 5초쯤 걸립니다.
- MediaPipe 파일을 CDN에서 받으므로 인터넷이 필요합니다.

## 단계

왼쪽 창에는 그 손동작으로 앱에서 무엇을 하는지(BPA 360에서는)와 기기에서 다른 점(Vision Pro에서는)이 나옵니다.

| 단계 | 웹캠에서 하는 동작 | 앱에서 쓰는 곳 |
|---|---|---|
| 1 맞대기 | 엄지·검지를 3번 맞댔다 떼기 | 모든 조작의 기본 핀치 |
| 2 누르기 | 도구 막대의 그룹화 → 스티커 → 방향 펜 누르기 | 버튼 (보고 핀치) |
| 3 그룹 만들기 | 같은 방향 혈흔 3개를 사각형으로 감싸고, 혈흔 유형 분류 창에서 대분류를 골라 그룹 생성 | 클러스터링 그룹화 (오른손 광선 + 핀치) |
| 4 스티커 | 방향 화살표를 끌어 붙이고, 골라서, 회전을 누르고, 링 손잡이를 돌려 ✓로 확정 | 방향 스티커 붙이기·회전 |
| 5 줄 잇기 | 흰 점을 집어 점선 원까지 줄 3개 잇기 | 방향성 판단의 줄 연결법 |

## 운영자용 키

- `←` `→` 단계 이동, `R` 이 단계 다시, `Esc` 처음 화면
- 웹캠이 안 되면 첫 화면의 **마우스로 해보기** (클릭 = 맞대기)
- 완료 화면은 25초 뒤, 연습 중 45초 동안 손이 안 보이면 처음 화면으로 돌아갑니다.

## 감도 조정

현장에서는 `[` `]` 키로 핀치 민감도를 1~5단계로 바꿉니다. 1이 가장 둔하고 기본은 3입니다. 바꾼 값은 그 브라우저에 저장됩니다.

더 고치려면 `index.html` 위쪽 상수를 바꿉니다.

- `PINCH_LEVELS`: 단계별로 맞댐으로 보는 엄지·검지 3D 거리 (손바닥 길이 대비). 카메라 창의 **지금** 값이 **맞댐 기준**보다 작으면 맞댄 것으로 봅니다.
- `PINCH_START_FRAMES` / `PINCH_END_FRAMES`: 몇 프레임 연속으로 맞대거나 떼야 인정할지
- `REACH`: 카메라 화면 중 벽 전체로 늘릴 범위. 팔을 많이 움직여야 하면 범위를 좁힙니다.
- 손은 가슴 높이에서, 카메라에서 한 뼘 넘게 떨어뜨려야 잘 잡힙니다. 손이 얼굴 앞에 있거나 너무 가까우면 값이 크게 흔들립니다 (카메라 창에 "손이 너무 가까워요"가 뜹니다).
- `ALIGN_TOLERANCE`: 스티커 방향을 맞았다고 보는 각도 차이.
