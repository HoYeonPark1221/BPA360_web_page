# 시연 전 손동작 연습

Vision Pro를 쓰기 전에 맥북 웹캠으로 BPA 360의 손동작 6가지를 연습하는 페이지입니다. 기기를 못 쓰는 사람(안경, 메이크업, 대기 시간)도 앱 흐름을 간접으로 체험할 수 있습니다.

- 주소: https://hoyeonpark1221.github.io/BPA360_web_page/practice/
- 처음 열 때 카메라를 허용하면, 손 인식 모델을 불러오는 데 5초쯤 걸립니다.
- MediaPipe 파일을 CDN에서 받으므로 인터넷이 필요합니다.

## 단계

왼쪽 창에는 그 손동작으로 앱에서 무엇을 하는지(BPA 360에서는)와 기기에서 다른 점(Vision Pro에서는)이 나옵니다.

| 단계 | 웹캠에서 하는 동작 | 앱에서 쓰는 곳 |
|---|---|---|
| 1 맞대기 | 엄지·검지를 3번 맞댔다 떼기 | 모든 조작의 기본 핀치 |
| 2 누르기 | 도구 막대의 그룹화 → 스티커 → 방향 펜 누르기, 세부 유형 목록을 스크롤해 ‘이차튐혈흔’ 누르기 | 버튼 (보고 핀치), 목록 스크롤 |
| 3 그룹 만들기 | 같은 방향 혈흔 3개를 사각형으로 감싸고, 혈흔을 가린 분류 창을 아래 막대로 옮긴 뒤, 대분류를 골라 그룹 생성 | 클러스터링 그룹화 (오른손 광선 + 핀치), 창 옮기기 |
| 4 스티커 | 방향 화살표를 끌어 붙이고, 골라서, 회전을 누르고, 링 손잡이를 돌려 ✓로 확정 | 방향 스티커 붙이기·회전 |
| 5 타원 맞추기 | 확대창의 타원을 Leading edge(돌리기)·끝(길이)·옆(폭)·안쪽(옮기기)으로 혈흔 몸통에 맞추고 측정 완료 | 방향성 판단의 축 측정 (충돌각) |
| 6 줄 잇기 | 흰 점을 집어 점선 원까지 줄 3개 잇기 | 방향성 판단의 줄 연결법 |

완료 화면에는 연습하지 않는 기기 조작(키보드 받아쓰기, Digital Crown 길게 눌러 다시 가운데로)을 안내합니다.

## 운영자용 키

- `←` `→` 단계 이동, `R` 이 단계 다시, `Esc` 처음 화면
- 웹캠이 안 되면 첫 화면의 **마우스로 해보기** (클릭 = 맞대기)
- 완료 화면은 25초 뒤, 연습 중 45초 동안 손이 안 보이면 처음 화면으로 돌아갑니다.

## 감도 조정

`index.html` 위쪽 상수를 고칩니다.

- `PINCH_ON` / `PINCH_OFF`: 맞댐으로 보는 엄지·검지 거리 (손바닥 크기 대비). 너무 예민하면 `PINCH_ON`을 낮춥니다.
- `REACH`: 카메라 화면 중 벽 전체로 늘릴 범위. 팔을 많이 움직여야 하면 범위를 좁힙니다.
- `ALIGN_TOLERANCE`: 스티커 방향을 맞았다고 보는 각도 차이.
- `AXIS_FIT`: 타원을 맞았다고 보는 범위 (가운데 거리, 축 각도, 장축·단축 길이 비율). `AXIS_GAIN`은 손잡이가 손을 따라오는 비율.
